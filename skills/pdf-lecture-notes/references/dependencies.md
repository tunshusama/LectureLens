# Dependencies and licensing

Install the Python dependencies from the installed Skill directory:

```bash
python3 -m pip install -r <installed-skill>/requirements.txt
```

PyMuPDF is not covered by this Skill's MIT license. Its maintainers offer it under GNU AGPL v3 or a separate commercial license. Tell the user this before installing dependencies, especially for organizational, redistributed, or proprietary use. Do not install it silently and do not present this note as legal advice.
