# Contributing

Contributions are welcome. Open an issue before a large workflow or schema change so compatibility can be discussed.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -v
```

Keep `SKILL.md` concise and route output-specific details to references. Add or update tests for schema, routing, parsing, rendering, or bug fixes. Examples must be self-created or redistributable and contain no personal data, credentials, private course material, or generated user artifacts.

By submitting a contribution, you agree that it may be distributed under this repository's MIT license.
